# Pyatkov_MSiRI-202_VR
# VR-тренажер: Вертикально-фрезерный станок с ЧПУ

## 1. Описание проекта
Интерактивная VR-сцена производственного цеха с вертикально-фрезерным станком с ЧПУ. Симуляция позволяет взаимодействовать со станком, устанавливать заготовки и управлять рабочим циклом с получением актуальных координат с сервера.

## 2. Запуск проекта
1. Убедиться, что запущен локальный/удаленный сервер, отдающий координаты шпинделя и стола в формате JSON.
2. Открыть проект в **Unity** (версия: `6.0`).
3. В окне `Project` перейти в папку `Assets/Scenes` и открыть финальную сцену `Factory vr`.
4. Подключить VR-шлем (или запустить XR Device Simulator для теста на ПК) и нажать кнопку **Play**.

## 3. Управление и функционал
* **Перемещение и взаимодействие**: Контроллеры VR (телепортация / стики для передвижения, кнопка захвата `Grip` для взаимодействия с объектами, луч/касание для нажатия UI-кнопок).
* **Двери станка**: Открываются и закрываются вручную при взаимодействии.
* **Установка заготовки**: Заготовка берется контроллером и помещается в триггер-зону на рабочем столе, после чего фиксируется и перемещается синхронно со столом.
* **Панель управления (Canvas)**:
  * Кнопка **«ПУСК»** — запускает рабочий цикл обработки на заданное время (по умолчанию **10 секунд**, настраивается в инспекторе).
  * Кнопка **«СТОП»** — принудительно останавливает работу станка.
  * **Дисплей координат** — в реальном времени отображает координаты перемещения шпинделя и рабочего стола, получаемые с сервера.
