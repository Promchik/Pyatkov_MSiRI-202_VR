1)Зачем скрывать поля класса?
Чтобы скрыть внутреннее устройство объекта, защитить его данные от неверных значений и не допустить перехода объекта в некорректное состояние при доступе снаружи.

2)Чем свойство отличается от поля?
Поле — это переменная внутри класса, которая является хранилищем данных и непосредственно хранит значение. Свойство — это член класса, которое само по себе данных не хранит, а представляет собой механизм контролируемого доступа к полю через аксессоры get и set, позволяя добавлять логику и проверки.

3)Что произойдёт, если не объявить ни одного конструктора?
Компилятор автоматически создаст базовый конструктор по умолчанию (без параметров), чтобы объект можно было создать через new.

4)Как конструктор связан с инкапсуляцией?
Конструктор обеспечивает контроль создания объекта, гарантируя, что с самого начала его жизненного цикл объект будет приведен в корректное и валидное начальное состояние в обход прямых изменений скрытых полей. Вместе с приватными полями и свойствами конструктор образует надежный класс.

5)Можно ли изменить свойство только для чтения после создания объекта?
Нет, свойство только для чтения защищает от изменений после создания объекта. Если у свойства есть только аксессор get или get с инициализацией в конструкторе public string Id { get; }, его значение задается при создании и не может быть изменено позже.
