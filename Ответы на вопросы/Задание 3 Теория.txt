1. Отличие коллайдера от коллизии
 Коллайдер (Collider): Компонент на игровом объекте, который определяет его физическую форму для просчета физики.
 Коллизия (Collision): Само событие столкновения двух объектов, у каждого из которых есть коллайдер.

2. Отличие while от do while
while: Цикл с предусловием. Сначала проверяет условие, а затем выполняет код. Если условие изначально ложно, код не выполнится ни разу.
do while: Цикл с постусловием. Сначала выполняет код, а затем проверяет условие. Код выполнится минимум один раз в любом случае.

3. Методы Web-запросов
Основные HTTP-методы, используемые при работе с сетью:
GET: Получение данных с сервера.
POST: Отправка новых данных на сервер.
PUT / PATCH: Обновление существующих данных на сервере.
DELETE: Удаление данных на сервере.

4. Когда используется OnCollision и OnTrigger
OnCollision (Enter/Stay/Exit): Используется для твердых физических столкновений, когда объекты должны отталкиваться друг от друга.
OnTrigger (Enter/Stay/Exit): Используется для триггеров, когда объект должен пройти сквозь область, но зарегистрировать это.

5. Для чего нужен класс/интерфейс Input
В Unity класс Input отвечает за считывание ввода от пользователя: нажатия клавиш клавиатуры, кнопок мыши, движения геймпада, касания экрана смартфона или наклоны гироскопа.
